# 日語單字卡學習網站 — 作業專案

## Project Overview

本專案為前端網頁設計課程作業，使用 HTML、CSS 與 JavaScript 製作一個互動式日語學習網站。
透過單頁式 HTML 設計與基本網頁技術，建立多個可操作的學習頁面，並整合為一個可在線上瀏覽的網站。

網站包含平假名挑戰、翻面單字卡與旅遊常用語等內容，並加入語音播放與動畫效果，提升學習互動性與使用體驗。

## Features

本專案包含以下功能：

* 首頁導覽頁面（index.html）
* 平假名配對挑戰
* 日文水果翻面單字卡
* 日文動物翻面單字卡
* 日本旅遊常用語翻牌卡
* 卡片點擊翻面動畫
* 日文語音播放功能（Web Speech API）
* 語速切換（慢速 / 普通 / 快速）
* 回首頁按鈕導航
* 背景動畫效果（水果掉落、飛機動畫等）
* 響應式版面（手機與桌面皆可使用）

## Technologies Used

本專案使用以下技術製作：

* HTML
  建立頁面結構與卡片內容

* CSS
  設計版面配置、色彩風格、翻牌動畫與背景動畫

* JavaScript
  控制翻牌互動、語音播放、語速切換與事件處理

* Web Speech API
  實作日文發音播放功能

* GitHub Pages
  部署靜態網站並提供線上瀏覽
